# TaskFlow

A clean and responsive personal task planner built with **HTML, CSS, and JavaScript**.

TaskFlow helps users organize their tasks by priority, deadline, category, and estimated time while tracking overall progress.

## ✨ Features

* Create and add tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Set task priority:

  * High
  * Medium
  * Low
* Organize tasks by category:

  * Work
  * Study
  * Personal
  * Other
* Add deadlines
* Set estimated completion time
* Filter tasks by:

  * All
  * Active
  * Completed
* Filter tasks by priority
* Automatically organize tasks into:

  * **Do Now**
  * **Do Next**
  * **Later**
* Dashboard statistics for:

  * Total tasks
  * High-priority tasks
  * Tasks due today
  * Completed tasks
* Automatic progress calculation
* Light and dark mode
* Current date display
* Task data persists using browser `localStorage`

## 🛠️ Technologies Used

## 🧠 How It Works

Tasks are created through the task form, where users can specify the task name, priority, category, deadline, and estimated time.

JavaScript dynamically creates and renders task cards and automatically places tasks into the appropriate section based on their priority and deadline.

Task data is stored in the browser using `localStorage`, allowing tasks to remain available after refreshing the page.

The dashboard also updates automatically as tasks are added, completed, edited, or deleted.
